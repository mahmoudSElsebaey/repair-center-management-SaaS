# دليل استخدام منصة RepairFlow

**دليل شامل بالعربية — يشرح المنصة، الهدف منها، الأدوار، والميزات، وكيفية الاستخدام خطوة بخطوة.**

---

## 1. ما هي منصة RepairFlow؟

**RepairFlow** منصة تشغيل متكاملة لمراكز صيانة وإصلاح الأجهزة (هواتف، لابتوب، أجهزة منزلية، تكييف، وغيرها).

تغطي المنصة دورة العمل الكاملة من استلام الجهاز حتى التسليم والضمان، مع دعم:

- إدارة العملاء والأجهزة وتذاكر الإصلاح
- الفنيين والصلاحيات والمخزون
- عروض الأسعار وموافقة العميل
- الفواتير والمدفوعات
- تتبع عام للعميل عبر رمز QR
- جدولة المواعيد والتقارير والإشعارات
- واجهة ثنائية اللغة (عربي / إنجليزي) مع RTL

التقنية: **MERN** (MongoDB · Express · React · Node.js) مع TypeScript و Tailwind.

| أمان وصلاحيات | كل مستخدم حسب دوره والفرع |

## 5. التدفق التشغيلي

```
استقبال → عميل + جهاز → تذكرة إصلاح → تشخيص/عرض أسعار → موافقة
→ تنفيذ → فاتورة → مدفوعات → تسليم (+ ضمان)
```

التتبع: `/track/RF-YYYY-#####` أو QR من تفاصيل التذكرة.

---

## 6. خطوات سريعة

1. **دخول:** البريد + كلمة المرور → `/app`
2. **عميل وجهاز:** القائمة → العملاء → إضافة
3. **تذكرة:** التذاكر → جديدة → حالات السير
4. **عرض أسعار:** من التذكرة → إرسال للموافقة
5. **فاتورة ودفع:** إصدار فاتورة → تسجيل دفعة
6. **مواعيد:** تقويم أسبوعي + منع تعارض الفني
7. **مخزون:** أصناف + حركات + تنبيه النقص
8. **تقارير:** فترة 7/30/90 يوم + KPIs

## 7. التشغيل المحلي

